# Hai, Guru! 💐

Website kartu ucapan untuk guru. Dibuat menggunakan HTML, CSS, dan JavaScript murni — tanpa database, backend, atau framework.

## Menjalankan
Buka `index.html` di browser.

## Cara kerja link pesan
Pesan disimpan di dalam URL (hash) menggunakan encoding, bukan database. Saat tombol **Kirim pesan** diklik, link khusus pesan otomatis disalin ke clipboard. Penerima membuka link itu dan langsung melihat ucapan. Karena isi pesan ada di URL, jangan masukkan informasi pribadi atau rahasia.
